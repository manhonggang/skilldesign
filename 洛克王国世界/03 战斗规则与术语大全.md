# 战斗规则与术语大全

共 54 条战斗术语，全部转录自 Wiki `Module:Pets/data/Terms`（技能描述中的脚注即引用这些术语）。以下按主题分组，**描述为游戏原文**。

## 持续伤害类状态

| 术语   | 效果说明                                                                |
| ---- | ------------------------------------------------------------------- |
| 中毒   | 回合结束时，造成3%生命的毒系伤害。（毒系精灵免疫此效果）                                       |
| 灼烧   | 回合结束时，造成2%生命的火系伤害，并衰减一半层数。（火系精灵免疫此效果）                               |
| 寄生   | 回合结束时，从寄生来源吸收2%生命。（草系精灵免疫此效果）                                       |
| 冻结   | 冻结5%生命，若当前生命低于冻结比例，则力竭。（冰系精灵免疫此效果）                                  |
| 减益   | 降低属性、技能威力、连击数，以及增加能耗、中毒、灼烧、寄生、冻结、萌化、引电等效果。（不包括类型为“印记”、“特性”、“其他”的效果） |
| 附加中毒 | 使用附加中毒X的技能会使敌方获得X层中毒。                                               |
| 中毒效果 | 包括中毒和中毒印记。                                                          |
| 中毒印记 | 印记效果，回合结束造成3%生命的毒系伤害。                                               |
| 属性增益 | 增益的其中一种类型，指提升物攻、魔攻、物防、魔防、速度的增益。                                     |
| 属性减益 | 减益的其中一种类型，指降低物攻、魔攻、物防、魔防、速度的减益。                                     |

## 离场 / 入场规则

|术语|效果说明|
|---|---|
|离场|通过主动更换精灵或触发脱离效果的方式下场。（不包括精灵力竭后下场）|
|脱离|精灵离场，并选择队伍里一只其他精灵替换入场。本回合入场的精灵免疫此效果。|
|紧急脱离|精灵离场，并随机选择队伍里一只其他精灵替换入场。本回合入场的精灵免疫此效果。|
|返场|精灵离场，并立即入场。本回合入场的精灵免疫此效果。|
|禁足|处于禁足状态时，精灵无法离场，且无法获得新的禁足状态。|
|迅捷|通过主动更换精灵的方式入场时，使用第一个能量满足要求，并带有迅捷的技能。|
|迸发|入场后的首次行动，会获得额外效果。|

## 行动规则

|术语|效果说明|
|---|---|
|先手|技能行动的优先级，先手度更高的技能忽略双方精灵速度差异，优先释放，先手度可叠加。|
|应对状态|若敌方使用状态技能，则本技能应对成功，本次行动必定先手，且触发应对效果。|
|应对攻击|若敌方使用攻击技能，则本技能应对成功，本次行动必定先手，且触发应对效果。使用后，携带的防御技能进入1回合冷却。|
|应对防御|若敌方使用防御技能，则本技能应对成功，本次行动必定先手，且触发应对效果。|
|打断|使敌方本次无法释放对应技能。|
|蓄力|该技能需要先蓄力1回合，下回合才能释放。蓄力期间免疫所有离场效果。|
|连击数|改变连击次数，仅对有连击的技能生效。|
|选择|可以从2个效果中选择1个使用。（2个效果视为相同技能，分别记为「明」和「暗」）|
|巧变|使用后会变为指定范围内的随机技能，且能耗-1。使用该随机技能后会变回原技能。|
|传动|回合开始时，带有“传动X”的技能会向下移动X个位置，该效果可叠加。|

## 增益 / 减益 / 吸血

|术语|效果说明|
|---|---|
|增益|增加属性、技能威力、连击数，以及降低能耗、吸血、过载等效果。（不包括类型为“印记”、“特性”、“其他”的效果）|
|吸血|造成伤害时，根据吸血比例和造成伤害值，回复生命。|

## 印记系统

|术语|效果说明|
|---|---|
|印记|精灵下场后印记不会消失，新入场的精灵会继承印记效果。精灵最多同时拥有1种正面印记和1种负面印记。|
|攻击印记|印记效果，全技能威力+10%。|
|棘刺印记|印记效果，场上的精灵离场后，更换入场的精灵失去6%生命。|
|光合印记|印记效果，回合结束时获得1能量。|
|湿润印记|印记效果，全技能能耗-1。|
|蓄电印记|印记效果，攻击技能获得迸发：本次威力+10。|
|风起印记|印记效果，先手攻击时，本次技能威力+20%。|
|降灵印记|印记效果，场上的精灵离场后，更换入场的精灵失去1能量。|
|蓄势印记|印记效果，全攻击技能威力+30%，且能耗+1。|
|龙噬印记|印记效果，释放3能耗技能后，获得双攻+40%。|
|减速印记|印记效果，速度-10。|
|星陨印记|印记效果，使用非幻系技能攻击拥有此印记的精灵时，会触发星陨印记，消耗全部星陨层数，对其造成额外的幻系伤害。|
|暗涌印记|印记效果，场上的精灵离场后，更换入场的精灵获得随机5层属性减益。|

## 特殊形态与状态

|术语|效果说明|
|---|---|
|萌化|退化到上一阶，种族资质相应降低。（可退化的精灵才可以获得萌化，下场不会消失）|
|木桶状态|该状态下会隐藏精灵的信息，自己行动或被敌方攻击时解除。|
|月陨星状态|该状态下会隐藏精灵的信息，自己行动或被敌方攻击时解除。|
|混血精灵|非本系血脉的精灵，包括非本系的系别血脉、首领血脉、奇异血脉、污染血脉等。|
|引电|获得2层引电时，立即受到25%生命的电系伤害，并失去2层引电。（电系精灵免疫此效果）|

## 天气系统

|术语|效果说明|
|---|---|
|沙暴|天气为沙暴时，双方的地系技能能耗减半。|
|暴风雪|天气为暴风雪时，双方每回合结束获得2层冻结。（冰系精灵免疫此效果）|
|雨天|天气为雨天时，双方的水系技能威力+75%。|
|雷鸣|天气为雷鸣时，双方每回合结束获得1层引电。（电系精灵免疫此效果）|

## 未分组术语

|术语|效果说明|
|---|---|
|奉献|使己方队伍中所有的「啃咬」和「虫群」技能获得奉献对应的强化效果。|
|萌芽印记|获得增益时，会额外获得1层。|

> [!tip] 与宝可梦的关键差异
> 本作没有 PP 概念，改用**魔力/能量**（技能有「能耗」字段）；防御技能带「应对」判定；精灵**力竭**而非濒死；印记在换人后**继承**；存在「萌化」（退化）、「木桶状态」（隐藏信息）、「巧变」（技能随机变形）等独特规则。
